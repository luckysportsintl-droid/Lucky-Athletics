# Add a new pattern to all product mockups

## Option 1 — another design using an existing pattern layout

Open `lib/catalog.ts`. After the existing `export const designs ...` line, add:

```ts
designs.push({
  id: 25,                    // Must be unique. Do not rename existing IDs.
  name: 'Club Chevron',
  motif: 'chevron',
  primary: '#142747',
  accent: '#E9263F',
  trim: '#FFFFFF',
});
```

Supported motifs: `chevron`, `diagonal`, `stripes`, `gradient`, `split`, `curves`, `pinstripe`, `zigzag`, `triangles`, `hoops`, `solid`, `camo`, `bolt`, `shards`, `waves`, `grid`, `slashes`, `yoke`, `fade`, `sash`, `dots`, `angles`, `border`, `two-tone`.

Run:

```bash
pnpm mockups
pnpm check
pnpm verify:mockups
pnpm verify:interactions
pnpm build
```

The script creates previews for every category automatically. Existing category codes combine with the new ID, for example `LA-BB-25`. Re-upload **dist/** to your existing Netlify site. The gallery and previous/next navigation use the design array length, so no component editing is needed.

## Option 2 — use your own artwork file

1. Export a square PNG or WebP, ideally 1024 × 1024 or larger. Use actual pattern artwork without garment outlines, background presentation boards or page labels. Export Illustrator artwork to PNG first.
2. Place it at `public/patterns/my-club.png` (create `patterns/` if needed).
3. Add the following entry after the existing `designs` declaration:

```ts
designs.push({
  id: 26,
  name: 'My Club',
  motif: 'custom artwork',
  primary: '#142747',
  accent: '#E9263F',
  trim: '#FFFFFF',
  texture: '/patterns/my-club.png',
});
```

4. Run the same commands above and upload the rebuilt **dist/**.

Custom artwork is fitted to the printable panel region, rather than automatically tiled. Transparent artwork overlays the selected primary color. Fixed artwork colors are preserved; automatic color buttons are hidden for entries with `texture`. For selectable colors, define the artwork procedurally in `lib/design-texture.ts` or supply separately colored artwork entries.

## Add a genuinely new procedural motif

Add a `case` in the switch in `lib/design-texture.ts`. Draw within its logical 512 × 512 canvas using `design.primary`, `design.accent` and `design.trim`. Then use that motif name in a design entry. The same texture function feeds the offline renders and live color previews.

## Change the product template

The source atlases are `public/templates/products-1.png` and `products-2.png`. Each has four columns and three rows, with transparent space outside each product. The `sheet` and `cell` values in `lib/catalog.ts` identify each category. Keep the same registration when replacing an atlas.

Use neutral light-gray, front-view, transparent product images with visible fabric folds. Dark zippers, straps and hardware stay dark. No printed stripes, colored panels, text or logos should remain in a neutral template.

`pnpm mockups` crops the atlases to category `.webp` templates, then generates 320 × 360 and 640 × 720 product images. Do not edit the cropped templates alone: they are regenerated from the source atlases. For a custom silhouette or different top/bottom positions, adjust the normalized panel rectangles in `lib/mockup-renderer.ts` and inspect the contact sheet generated by `pnpm verify:mockups`.

Template pixels supply the transparency, shading and fabric relief. The renderer removes small isolated residue, maps a texture separately to each garment piece and gently displaces it according to fold lighting. This is a product visualization, not a production sewing/panel map or a rotating 3D model.
